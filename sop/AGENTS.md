# 此目录的工作约定

这是 TapTap Maker 开发 SOP v2.0 资料库，不是 Maker 游戏项目。先读 README.md 与 docs/流程/总流程.md，再按当前任务读取最少必要章节。

- **保护现场**：保留现有文件、项目规则、未提交工作与正式存档；严禁 `git reset`、`git clean` 或覆写不明来源文件。
- **AI 防乱改纪律**：改前先读目标模块与调用链；最小必要改动，不顺手重命名稳定存档字段、不乱动无关 UI 布局、不以清档或放宽风控掩盖真 Bug。
- **资产与画面**：图片干净无噪点，正式 UI 文字使用真实字体组件；3D 场景先出平面动线图与白模验证再堆精模；`.meta` 与 UUID 仅由官方工具生成。
- **明确授权红线**：本地预览与按需重启已允许；构建、上传、推送远端与线上实验发布必须另有明确授权。
- **仓库隔离**：绝不将本资料库初始化为 Maker 项目，不借用其他游戏的绑定配置；QA/诊断 HTML 报告、验收视频与测试存档绝不混入游戏打包目录。
- **证据分级**：绝不将静态检查、隔离模拟、资源试听、本地预览、远端构建与真机平台验收混写成同一种通过。
- **第三方与样例**：`library/sources` 中第三方内容只读研究不执行；`samples/breakfast` 保持延后状态，未经新指示不补跑。
- **索引同步**：Markdown 是正文源，`portal/catalog.js` 由 `scripts/build_portal.py` 生成；改正文后同步并跑 `scripts/validate.py`。
