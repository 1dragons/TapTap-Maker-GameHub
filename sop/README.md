# TapTap Maker 小游戏开发 SOP

版本：2.0.0 · 2026-11-27 · 适用：独立游戏创作者 + AI 编程助手（Antigravity / Codex / Cursor）+ TapTap Maker（UrhoX + Lua）

这套制作体系沉淀自多款已上线 2D / 3D、横屏 / 竖屏 TapTap Maker 小游戏的实战闭环，覆盖「立项原型 → 视觉与 3D 空间基线 → 分批正式制作与工程防线 → 发布前全量 QA → 运营资料与授权发版 → 数据 × 玩家原声双驱迭代」。它不能保证流量，也不把功能完成等同于体验达标。

## 从这里开始

- 在 **GameHub 游戏总控台** 左侧点击「**SOP 中心**」，即可直接交互浏览完整 11 阶段闭环、全文搜索手册、实时预览 5 款开源中文字体、查看资源样例并一键为游戏项目接入 SOP。
- 了解 [总流程与阶段标准](docs/流程/总流程.md)（含四技能 + GameHub 协同分工）。
- UI 与 3D 场景按 [UI 视觉基线与实现（分级出图工作流）](docs/流程/UI设计稿到实现.md) 执行：核心基线先定调，常规弹窗按 Design Token 直出，实机多比例验收。
- 生产级避坑必读：[Maker 开发规范](docs/规范/Maker开发.md) 与 [存档演进、防刷风控与数值安全规范](docs/规范/存档与风控.md)。
- 新项目、已有项目与日常按需路由：读 [项目接入与日常调用](docs/流程/项目接入.md)。
- 当前证据与缺口：[交付验证记录](docs/交付验证.md)。

## 一句话调用示例

- **新项目**：使用 `$taptap-maker-sop` 为当前 Maker 项目接入 `<SOP根目录>`，保留已有文件与规则。我的想法是：……
- **继续项目**：在 GameHub 点击「复制 AI 上下文」，粘贴后使用 `$taptap-maker-sop` 继续下一项已授权工作。
- **发版前体检**：使用 `$taptap-maker-qa` 对当前项目执行发布前全量 QA 体检、自动修复并出 HTML 看板。
- **版本运营资料**：使用 `$mini-game-version-ops` 准备本版本的运营文案和 16:9 / 2.5:1 头图。
- **上线后数据诊断**：使用 `$game-diagnosis` 分析 GamePropel 留存与漏斗数据并输出 ≤3 个优化建议看板。

## 人机分工与不可逾越的红线

你负责决定体验方向、核心取舍以及三道人工确认门禁（**玩法方向确认 / 样板确认 / 构建上传明确授权**）；AI 助手负责研究、设计、按规范实现、本地预览、QA 自动修复与分级别记录证据。**发布候选确认不等于构建上传授权**，任何阶段均不得未经授权自动构建、上传或修改线上配置。

## 目录结构

- `docs/流程`：总流程、项目接入、立项研究、原型与样板、UI 分级出图、正式制作与 QA、数据与玩家双驱迭代。
- `docs/规范`：玩法经济、界面与全比例适配、美术与 3D 场景、字体排版、音乐音效与震动、Maker 生产避坑与 AI 协作纪律、存档与风控、OPT 广告与口碑红线、参考案例拆解、发布与运营。
- `docs/模板`：精简可复用制作记录模板，按需采用，不搞重文档负担。
- `library`：固定版本参考源码、开源中文字体清单与授权说明（第三方源码只读研究，不执行其脚本）。
- `samples/breakfast`：示例生成待办（保持延后状态）。
- `skill/`：内置完整 TapTap Maker 四件套 AI 技能源文件（`taptap-maker-sop`、`taptap-maker-qa`、`game-diagnosis`、`mini-game-version-ops`），可在 GameHub 一键安装到 Antigravity / Codex / Claude Code / Cursor。
- `scripts`：项目接入、资源下载、门户索引构建与一致性校验脚本。

## 维护与迁移

修改文档或资源清单后，运行 `python scripts/build_portal.py` 与 `python scripts/validate.py` 校验本地链接与隔离接入安全。已接入 v1.0 的游戏项目保留其原有记录，不因中央 SOP 升级至 v2.0 被静默覆盖，按需评估迁移即可。
