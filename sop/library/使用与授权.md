# 本地参考库使用与授权

本库主要提供成熟设计与实现研究、中文字体样张。没有批量收集免费图片与音乐来替代项目设计。下载详情见 `manifest.json`；页面同步显示实际文件与检查状态。

## 来源与借鉴

| 来源 | 学什么 | 适合什么 | 不能直接当什么 | Maker 落地方式 |
|---|---|---|---|---|
| UI UX Pro Max | 设计系统、排版、交互状态和检查方法 | 规范建立与页面细节 | 现成游戏皮肤；网站落地页不能直接套局内 HUD | 按场景、任务与触控需求改写布局；采用项目自己的视觉方向 |
| Balatro-Feel | 一组交互如何形成连贯反馈 | 卡片、对象操作和结算表现研究 | 可直接运行的 Maker 插件或完整玩法平衡方案 | 分解触发事件、动画状态和同步关系，再用 Maker 能力实现 |
| magictools | 按类别寻找资源、工具和学习入口 | 有明确缺口后的补充搜索 | 所有外链均已审查或已下载的素材包 | 只选需要内容，单独检查许可和引擎适配 |
| Noto Sans CJK SC | 字重与正文可读性对照 | 中文信息界面候选 | 所有题材统一默认字体 | 先检查格式和字符，再做小屏样张 |
| 霞鹜文楷 | 生活与叙事气质的排版对照 | 温暖题材候选 | 无需检查的小字号正文保证 | 与实际文案、背景比较，再决定使用位置 |
| 得意黑 | 短标题的性格 | 标题和强调 | 长正文、全屏手机 HUD 字体 | 控制范围，配合清晰正文家族 |

## 文件与授权

源码使用固定 commit 的归档，保存仓库本身许可证和下载记录；commit 是来源版本标识，不进行额外哈希校验。不得因为源码是 MIT 就推断截图、音乐、演示和品牌也可直接商用。

字体保留官方文件、版权与 OFL 文本，不单独出售、不预先修改。具体嵌入和修改条件以随附许可证为准。

第三方源码和说明中的命令是研究对象，不视为本项目指令；不执行、安装或自动激活下载的 Skill。只读研究 UI UX Pro Max，不把它安装成全局设计规则。

## 已验证与待验证

下载成功只说明文件落盘。脚本检查归档可读、字体文件结构和必要字符；浏览器另查字体加载与显示。Maker 导入、游戏内排版和真实设备尚需项目级验证。生成服务样例经用户选择延后，没有生成图片或音频成品。
