# 音乐、音效与震动反馈规范

## 1. 从情绪与操作节奏出发

先列简明场景情绪表（进入、常态经营/探索、紧张压力、阶段成功、失败、暂停）。不要求每个界面都配独立 BGM——高频操作的模拟经营游戏优先保持清爽舒适的环境底噪或轻节奏循环，避免背景音乐与奖励音效互相打架。

使用音乐生成工具时，若需要纯音乐须显式指定 `instrumental`，并完整试听开头、尾奏与实际循环接缝，不把“开了 loop 开关”当成无缝循环证据。

## 2. 关键事件音效与震动（Haptic）配合表

声音与移动端轻震动（Haptic）协同能显著提升点击、收钱与解锁的爽感，但必须克制、分层、可关闭：

| 事件 | 声音目标 | 震动反馈（移动端） | 行为约束 |
| :--- | :--- | :--- | :--- |
| 常规点击 | 轻、短、不刺耳 | 可不震或极轻 | 高频连点做限频/合并，不叠爆音 |
| 收钱 / 交易成功 | 清脆愉悦、与飘字同步 | 轻震（Light） | 连续入账限制同时发声数与震动冷却 |
| 关键操作命中 / 工具交互 | 贴合材质质感（金属/木头/液体等） | 轻~中震（Medium） | 与动画关键帧精准对齐 |
| 升级 / 解锁 / 里程碑 | 有层次感的阶段正向反馈 | 中震或短双震 | 不长时阻断下一次操作 |
| 资源不足 / 误操作 | 温和低沉提示 | 极短提醒或不震 | 必须配合清晰视觉说明，静音也可理解 |
| 紧急状态 | 清晰但不烦躁的提醒 | 按间隔轻提醒 | 限频播放，避免循环轰炸 |

## 3. 工程整合与广告返回音频恢复铁律

1. **分轨控制与持久化**：音乐（BGM）、音效（SFX）与震动（Haptic）开关/音量分别控制并持久化到设置存档；切换即时生效。
2. **激励广告返回 / 切后台音频恢复（必检红线）**：
   - 移动端播放激励视频广告或切后台返回游戏后，常出现音频上下文挂起导致全游戏静音或 BGM 停播；
   - 必须在应用恢复前台回调与广告关闭回调中主动执行**音频上下文重建/恢复检查**，确保返回后点击音效与当前 BGM 立即正常响起，且不会出现双份 BGM 叠播。
3. **混音平衡与并发上限**：先调好常态音量，再校准奖励与紧急提示相对响度；为高频音效设最大并发实例数与最小触发间隔，防止同时收几十笔账时爆音破音。

## 4. 验收与证据分级

- **资源级试听**：确认无削波破音、无意外人声、开头无多余静音拖尾、循环接缝平滑。
- **游戏内与真机验收**：检查点击同步、高频连点、切页、静音持久化、**看广告返回音频重建**、外放与耳机听感；浏览器/桌面单文件试听不能替代真机音频焦点与震动验收。
