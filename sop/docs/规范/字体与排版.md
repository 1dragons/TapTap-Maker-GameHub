# 字体与排版规范

## 选型原则

避免默认细体贯穿全项目。字体根据题材和阅读任务选择，不能为了“有特色”牺牲正文清晰度。先做中文标题、按钮、长句、金额和倒计时对照样张，再在目标尺寸选择。

| 角色 | 选择依据 | 重点检查 |
|---|---|---|
| 标题 | 体现题材与气质，可选择有性格的字体 | 短词辨认、字面大小、描边与背景对比 |
| 正文 | 中小尺寸清晰，字形稳定、中文覆盖合适 | 最长文本、行距、笔画粘连、缺字 |
| 按钮 | 短指令清楚、字重适当、状态一致 | 两到六字及较长词、垂直居中、禁用状态 |
| 金额与数量 | 字形易辨、位数变化稳定 | 0/O、1/l、逗号、小数、负值、单位与最大数 |
| 倒计时 | 快速扫读、不因数字变化明显跳动 | 等宽数字能力、冒号、临界颜色与读屏顺序 |

单个项目先用一个正文家族，加一个必要的标题字体；第三种字体只有明确用途才引入。使用真实字重，不默认靠伪粗体修补过细正文。中文与西文、数字混排需比较基线和视觉大小。

## 首批候选的使用边界

- **Noto Sans CJK SC Regular / Bold**：信息密集正文与按钮的候选，并非所有项目固定默认。
- **霞鹜文楷 Regular**：温暖、生活、叙事题材候选；小字必须比较实际清晰度。
- **得意黑**：短标题和强调文字候选；作者明确不推荐正文排版和手机界面使用，不把它铺满 HUD 与列表。

下载本身不等于引擎已支持。保留官方文件和 OFL，先测试 Maker 对格式、字符、字重的实际处理，再定正式字体。不安装到系统，不预先裁剪修改。

## 排版规则

先确定正文字号作为比例基准，再安排标题、次级说明和数字层级。具体字号按项目画布和缩放验证；不要把网页 CSS px 直接当引擎坐标。普通字、强调字、禁用字均需足够对比。

重要文本允许换行并提供合适高度。动态数字使用预留宽度或稳定对齐；长名避免挤压价格与按钮。不要用把文字缩到不可读的方式解决所有溢出。描边与阴影只用于背景需要时，不能掩盖糟糕对比。

## 测试字串

街角早餐店｜设施升级｜订单已完成｜余额不足，请先完成订单。｜暂未解锁｜正在保存…

￥1,234,567.89　-120　0/8　99+　Lv.12　00:09　09:59　100%　返回／继续

再加入本项目全部 UI 文案、角色名和玩家输入范围，检查字体字符表和实际渲染。罕见昵称可能需要回退；回退字体应显式定义并在引擎验证，不能只依赖开发机系统字体。

## 包体与许可

只携带实际使用字重。全量字体体积、加载耗时应测量；若后续需要子集化，另行核实 OFL、保留字符与动态输入，不在首版提前裁剪。保留版权、许可证和来源，不单独出售字体文件。浏览器样张可读不代表 Maker 字体导入已通过。
