# 美术与 3D 场景资源规范

## 1. 每个项目建立独立视觉锚点

动工前先定题材情绪、2D/3D 路线、视角（俯视/斜 45°/第一人称/第三人称）与可承受成本，写入项目风格说明：主辅色、明暗对比、材质质感、光向、比例基准与禁止项（避免空泛形容词如“高级、精致”）。

风格一致不等于所有游戏长一个样；借鉴参考时只提炼布局层级与视觉对比语法，绝不直接盗用其他游戏的截图或角色作为正式资产。

## 2. 3D 场景搭建与动线验收规范（成熟项目实战流程）

3D 经营/漫游/关卡类项目最怕“模型堆得很满，但玩家卡门、遮挡看不清、交互抢焦点”，必须按以下四步推进：

1. **第一步：平面功能分区与动线图（Floor Plan）**
   - 搭建 3D 场景前先画平面布局图，标清：出生点、主通道宽度、核心交互点、扩建预留区、摄像机默认朝向与视野死角。
   - 确认主通道留足角色与 NPC 错身空间，避免窄口堵死或触发区互相重叠。
2. **第二步：白模盒体验证（Greybox）**
   - 先用简单几何体占位跑通移动、碰撞、镜头跟随、交互触发优先级与核心循环；**动线和碰撞没跑顺前绝不批量堆精模**。
3. **第三步：替换精模、贴图与灯光调色**
   - 严格控制移动端面数、DrawCall 与贴图分辨率，保证手机流畅帧率（目标 60FPS），必要时提供移动端画质档。
   - 重点排查三类 3D 高频视觉 Bug：
     - **遮挡淡出阴影跳变**：角色走到墙体/屋顶后触发透明淡出时，确保不会导致地面阴影闪烁或明暗突跳；
     - **穿模与地板穿插**：草丛/地面装饰不得穿透室内地板，NPC 坐姿/躺姿/起身碰撞箱防穿桌卡死；
     - **光照过曝或死黑**：在手机实机屏幕亮度下复核整体对比度，保证可交互物体一眼从背景跳出。
4. **第四步：多视角审阅与实机录屏验收**
   - 大场景/扩建版本推荐生成可视化 **场景审阅页 / 短实机录屏**（归档至 `.gitignore` 忽略的 `acceptance/` 目录，不打进游戏包），直观核查全局构图与走位体验。

## 3. AI 生图、3D 资产生成与入库纪律

1. **先样张，再批量**：先生成 1~2 张核心风格锚点图或关键资产小样，确认画风、光向、视角与轮廓后再带同一风格锚点批量扩展。
2. **画面洁净硬标准**：所有正式图片必须干净、**无噪点、无随机颗粒、无多余水印或乱码文字**；正式 UI 文字一律由引擎真实字体渲染，不让生图模型硬画小字按钮文案。
3. **透明切图检查**：带透明通道的贴图与图标必须核对是否真正透明、在深浅双底色下无白边/暗边、主体未裁断，且在小屏尺寸下依然一眼可辨。
4. **资源入库与元数据清洁**：
   - 按 `scenes / models / textures / ui / icons / audio / fonts` 清晰分组命名，全仓引用路径严格统一大小写；
   - `.meta` 与 UUID 必须通过官方 `generate_resource_meta` 生成，严禁手写或复制拼凑；
   - **定期清理无用资产**：替换旧模型/旧贴图后同步删除废弃源文件与孤立 `.meta`，原稿与候选废图归档至项目外目录，不塞进游戏包体。

## 4. 版权与素材来源

- 优先复用当前项目已有清晰资产与引擎原生组件；
- 外部免费商用素材逐项记录来源与许可证（代码开源协议不涵盖美术/字体/音乐版权）；
- 参考库仅用于研究与精选按需导入，严禁整包复制进游戏。
