# 界面与交互规范

## 1. 先定义页面目的，再分级制作

设计页面前先读项目核心循环、已冻结的 Design Token 与公共组件。常规页面按 [UI 视觉基线与实现](../流程/UI设计稿到实现.md) 分级推进：A 类核心主页面定视觉基准与 Token，B 类常规弹窗填写简明 [单界面设计表](../模板/单界面设计表.md) 后直接复用组件实现，不把原型期临时按钮堆砌成正式界面。

- **竖屏项目**：主体居中展示地图/店面/操作台，顶部稳定承载时间、货币与进度，底栏或下方承载主操作并避开系统手势区。
- **横屏 / 3D 项目**：保证视野中央与操作区通透；左手移动区与右手视角/交互区天然分离，信息卡片尽量贴近边缘折叠收纳，不把竖屏界面简单拉伸塞进横屏。

### 从参考案例提炼信息层级
拆解优秀作品时只迁移信息语法：「场景说明题材 → 状态位置稳定 → 卡片围绕单一对象聚合信息 → 主动作有清晰视觉权重」。必须按本项目题材重新定色板、字体、比例与图标，不复制参考截图资产，也不默认把所有指标排成同权重白框。

## 2. 全比例与平台安全区适配铁律（实战必查）

移动端设备比例跨度极大，**从第一版 HUD 起就必须同时覆盖三类屏幕比例**，杜绝上线后平板和长屏互相踩踏：

1. **三类比例基线**：
   - **4:3 平板（iPad 等）**：横向空间相对窄、纵向信息易挤压；顶栏、左侧/右侧浮窗与中央指引条必须设自适应间距与缩放上限，防止老板手机、顶栏、指引条与箭头互相重叠。
   - **16:9 标准屏**：作为基准比例核对主次留白与信息密度。
   - **20:9 及以上全面屏 / 刘海屏**：顶部留出状态栏与挖孔安全区，底部留出系统手势横条安全区，左右横屏时双侧均保留边缘安全距。
2. **平台悬浮胶囊避让（右上角重灾区）**：
   - TapTap / 小游戏宿主右上角常驻平台胶囊按钮（菜单/关闭）。游戏内**设置按钮、倍速条、顶部状态栏右端、关闭按钮**必须主动向内或向下避让安全区，严禁被平台胶囊遮挡或引发误点退出。
3. **动态飘字与顶部横幅防重叠**：
   - 加钱/收益飘字、系统广播横幅、新手指引条三者必须规划**互不交叉的固定槽位**（例如收益飘字固定在货币栏下方或左上角专属区域，横幅居中且单行限宽），高频连点时合并或排队播放，不糊屏。
4. **高频误触防护**：
   - 返回键、退出键、删档键与主操作区保持清晰隔离（例如返回键固定置于左下角低频安全位或弹窗左上角），绝不在玩家高频连点区域突然弹出广告按钮或消费确认框。

## 3. 通用交互纪律

- **权重清晰**：每个弹窗/页面只有一个明确主动作，颜色、形状、文字共同表意；用真实字体与统一图标，不把零散 emoji 当正式图标系统。
- **触控尺寸**：高频触控目标按逻辑单位约 `44–48` 起步并在真机/预览中校准手感；列表、滚动区与弹窗遮罩防事件穿透。
- **状态完备**：加载中、空列表、禁用（须写明原因）、成功、失败（须给恢复路径）五态齐全；连续点击与异步提交必须加防重入锁。
- **动效克制**：反馈紧贴被操作对象，动效可中断或合并，不用冗长不可跳过的动画阻断高频操作。
- **长文本与大数字**：重要文案合理换行，不靠省略号截断关键规则；大额货币、倒计时与超长玩家昵称（UTF-8 安全截断）必须预排。

## 4. 常用页面设计速查目录

按项目实际需要选用，静音时视觉仍须完整表达操作结果：

| 页面 | 核心信息顺序 | 必查状态 | 验收重点 |
| :--- | :--- | :--- | :--- |
| 启动与加载 | 品牌识别 → 真实阶段进度 | 初次、缓存、资源失败、超时重试 | 不伪造进度、不循环轰炸提示音 |
| 主菜单 | 场景氛围 → 主开始/继续 → 设置/存档 | 新游戏、有存档、恢复失败、版本号 | 主动作一眼可见、删档需二次确认 |
| 局内 HUD | 场景主体 → 目标/货币 → 快捷入口 | 常态、资源波动、紧急预警、暂停 | 4:3/16:9/20:9 全比例不重叠、避让右上角胶囊 |
| 订单 / 任务 | 回报与成本摘要 → 接取/执行 | 无任务、可接、进行中、完成、超时 | 防连点重复接单、倒计时不遮挡文案 |
| 设施 / 升级 | 当前效果 → 升级变化 → 价格 → 行动 | 可升、缺钱、未解锁、满级 | 升级结果同步落到场景视觉变化 |
| 商店 / 背包 | 余额稳定 → 效果与价格相邻 | 可买、已拥有、售罄、空背包 | 防重复扣费、获得反馈清晰 |
| 结算页 | 结果 → 原因与贡献 → 奖励 → 继续 | 成功、失败、广告双倍可用/失败 | 奖励单次发放；广告按钮与基础领取严格区分 |
| 存档与设置 | 多槽位进度对比 / 音量与画质 | 正常、保存中、冲突、撤销备份 | 删档带二次确认与撤销备份；静音即时持久化 |
| 排行榜 | 口径说明 → 本人排名 → 榜单 | 加载、空、离线、风控屏蔽 | UTF-8 长昵称安全截断、大数字格式化 |
| 广告入口 | 明示观看条件与精确收益 | 可用、加载中、播放、未完成、成功 | 不伪装普通按钮、失败不扣成本不卡死 |

## 5. 必查边界场景

最长文本、最大合理数值、空列表、未解锁、资源不足、按钮连点、动画中途关闭、切后台/看广告返回、多弹窗叠加、**4:3 平板 + 16:9 + 20:9 全比例与右上角胶囊避让**。
