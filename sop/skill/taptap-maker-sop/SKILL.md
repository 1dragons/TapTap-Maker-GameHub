# TapTap Maker 小游戏开发 SOP v2.0

先确认中央 SOP 根目录（`{{SOP_ROOT}}`，可由用户、项目 `.sop/project.json` 或 GameHub SOP 配置指定）及 `README.md` 存在；不存在时报告具体路径，请用户指定位置，不假称已遵循 SOP。

## 入口与项目接入

1. 读取根目录 `README.md`、`docs/流程/项目接入.md`。确认当前工作区就是用户指定的游戏项目，严禁将 SOP 资料库当作游戏初始化。
2. 检查目标项目 `AGENTS.md`、`.sop/project.json`、进度、设计决定与实际源码。新接入使用 `scripts/connect_project.py --project <明确绝对路径> --mode new|existing` 或 GameHub「一键接入 SOP」，绝不覆盖已有规则、进度与正式存档。
3. 中央版本由 v1.0 升级至 v2.0 不静默推翻老项目设计，先评估受影响差异再记录迁移。
4. 继续项目时先核对实际代码现状，选择下一项已授权工作；专项小改动只读必要规范，不机械重跑全部阶段。

## 按任务按需读取

- **立项与原型**：`docs/流程/总流程.md`、`立项与参考研究.md`、`原型与品质样板.md`、`docs/规范/玩法与经济.md`。
- **界面与全比例适配**：`docs/流程/UI设计稿到实现.md`（分级出图：A 类基线定 Design Token，B 类常规弹窗直出）、`docs/规范/界面与交互.md`（4:3 平板 / 16:9 / 20:9 + 右上角平台胶囊避让 + 飘字防重叠）、`字体与排版.md`。
- **美术、3D 场景与声音/震动**：`docs/规范/美术与资源.md`（3D 先平面动线图 → 白模验证 → 精模渲染与阴影防跳变）、`音乐与音效.md`（含广告返回音频重建与移动端震动配合）。图片必须干净无噪点、真实字体渲染正式文字；遇 Maker 精灵生成不支持提示立即停止并告知限制。
- **Maker 实现、生产避坑与 AI 协作**：`docs/规范/Maker开发.md`（`dt` 钳制、多指触控 `touchId` 隔离、3D 触发器防抢占、生产 LSP 0 警告、大小写路径一致、`.gitignore` 防污染包体）与 `maker://status` 返回的当前指引文档。
- **存档、老档直升与排行榜风控**：`docs/规范/存档与风控.md`（显式 `saveVersion` 渐进迁移、多槽位 + 撤销备份、长周期老档瘦身、排行榜防刷风控、UTF-8 昵称截断与发版调试开关清零）。
- **广告与商业化**：`docs/规范/广告与商业化.md`（OPT 实战入口 + 严禁连续几十条广告逼看的 1★ 差评红线）+ `maker://ads-integration-guide` + `engine-docs/recipes/sdk.md`。
- **发布与双驱迭代**：`docs/流程/正式制作与验收.md`、`docs/规范/发布与运营.md`、`docs/流程/上线与迭代.md`。

## 四技能与 GameHub 职责移交

- **准备构建上传前全量体检** → 转交 **`taptap-maker-qa`**（静态审计 + 官方 Lua 校验 + 8 维逻辑与老档直升审查 + 自动修复回归 + HTML 看板）。
- **上线后留存/漏斗/广告数据分析** → 转交 **`game-diagnosis`**（GamePropel CLI 只读诊断 + ≤3 优化点 HTML 看板）。
- **新版本商店文案与 16:9 / 2.5:1 头图** → 转交 **`mini-game-version-ops`**。
- **日常总控、构建上传打卡与玩家评价/论坛排查** → 配合 **GameHub**（Git 演进树、三段打卡、TapTap 增量评价 AI 雷达）。

## 红线与交付纪律

- **AI 防乱改**：改前必读上下文与调用链；最小必要改动，严禁顺手改名稳定存档字段、乱改无关布局或以清档/放宽风控掩盖真 Bug。
- **三道人工门禁**：玩法方向、视觉/空间与声音样板、发布候选必须由用户明确确认；静默不算同意。
- **严禁未授权构建上传**：允许本地预览与按需重启；构建、上传、提交推送与线上实验发布必须另有明确授权（工具提示“需要构建”不构成授权）。严禁借用其他游戏的绑定配置。
- **保护现场与 6 级证据**：不执行 `git reset` / `git clean` 或覆写正式存档；静态、模拟、资源、官方 Lua 校验、本地预览与真机平台证据分项记录，未知项如实标注未运行；QA/诊断报告放项目外安全目录，绝不污染游戏包体。
