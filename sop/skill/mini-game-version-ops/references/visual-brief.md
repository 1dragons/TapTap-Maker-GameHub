# 游戏宣传图制作简报

在实际生图时读取。此文件不要求对用户重复展示或审批全部简报，信息足够时直接制作。

## 提取游戏识别特征

从真实截图/素材记录：游戏名称与现有Logo、主要角色或经营对象、场景时代、主色与点缀色、表现形式（像素/手绘/低多边形等）、常用视角、本次新增或改动元素。至少明确哪些对象必须保持，以及哪些更新能在图中表现。没有角色的游戏不强行添加人物。

图像以这款游戏及本次版本为主体。宣传插画可以调整构图和光影，但不能出现游戏中没有的新角色、新建筑、新皮肤或功能暗示。若本次只是修复优化，可用已有核心玩法场景和准确的优化主题文案，无需虚构新内容。

## 两张图分别构图

- 新版本头图：1920×1080，16:9。突出游戏识别元素和本次主题，适量保留环境；游戏名/原Logo、短版本主题及最多一句短卖点即可，避免把70字介绍塞入图片。
- 搜索品牌专区图：1920×768，2.5:1。复用视觉语言，独立安排主体与文字，以横向可读性为先；核心信息远离边缘，不能裁掉头像、Logo或标题。截图没有提供官方安全区，不捏造平台安全区参数。

每次提示词包含：图片用途、目标比例与最终尺寸、各参考素材作用、真实游戏对象、画风/颜色、真实更新主题、准确文字、必须保留项与需避免项。提供准确Logo原件时要求保持；文字生成不准确则针对性修正并复看。

## 验收

逐张检查最终图：与参考游戏匹配；两图视觉一致且布局适配；没有误导性内容；中文无错字乱码；文字缩小后仍清晰；主体未被裁坏。用图像工具读取实际尺寸和格式，不能仅根据提示词或文件名认定合格。若使用截图，应注明实机来源；AI插图标为宣传插图。不要把头图换比例后拉伸充作宽图。
