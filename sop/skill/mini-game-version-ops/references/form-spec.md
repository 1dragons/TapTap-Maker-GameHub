# 新版本介绍页字段规范

来源：用户2026-10-08提供的三张“创建新版本介绍页”后台截图。星号表示必填，尺寸提示是后台建议，本Skill按建议尺寸交付。后续后台变化以用户最新截图为准。

| 区域 | 字段 | 必填性 | 限制 / 处理 |
|---|---|---|---|
| 基础信息 | 版本名 | 必填 | 20字以内；截图提示提交审核后不可自行修改 |
| 基础信息 | 新版本卖点 | 必填 | 20字以内，抓住最值得玩家关注的一项变化 |
| 基础信息 | 新版本标签 | 必填 | 从下面列表选择1–3个，按真实更新匹配 |
| 基础信息 | 新版本介绍 | 必填 | 70字以内，概括本次主要更新 |
| 上线日期 | 新版本上线日期 | 必填 | 用户确认完整日期、时间与时区 |
| 上线日期 | 上线日期对外展示 | 必填 | 是 / 否，由用户确认 |
| 上架设置 | 是否定时上架 | 必填 | 立即上架 / 定时上架，由用户确认 |
| 上架设置 | 定时上架时间 | 条件需要 | 选择定时上架时提供，不得晚于新版本上线日期 |
| 上架设置 | 开放预约自动下载功能 | 必填 | 开放 / 不开放；先核实小游戏形态及后台适用性，再确认选择 |
| 主视觉素材 | 新版本头图 | 必填 | 建议1920×1080，16:9横图；交付该尺寸PNG/JPG |
| 主视觉素材 | 新版本视频 | 可选 | 仅MP4；上传后头图部分优先展示视频 |
| 主视觉素材 | 搜索品牌专区图 | 必填 | 建议1920×768，2.5:1横图；交付该尺寸PNG/JPG |
| 版本内容模块 | 标题 | 必填 | 15字以内；至少准备1个模块 |
| 划重点 | 条数 | 可选 | 一个模块最多5条，按填写顺序展示；默认有依据就生成 |
| 每条重点 | 标题 | 创建该条时必填 | 15字以内 |
| 每条重点 | 描述 | 可选 | 100字以内，默认生成具体体验变化 |
| 每条重点 | 媒体素材 | 可选 | 图片JPG/PNG最多5张，视频MP4最多1个；横图建议16:9且不低于1280×720；竖图建议9:16且不低于720×1280 |

可选标签原文：新主线、新赛季、新皮肤、限时活动、新玩法、新职业、新地图、新门派、新角色、新DLC、新副本、新系统、联动、新剧情。
